# Changelog

## v0.6.1 · 2026-09-13

- 与 dsh 侧 npm 包对齐版本号；npm 包补上 dsh-plugin 关键字标签，让 1024 商店认得出 npm 安装方式
- 功能与 0.6.0 完全一致，已装 0.6.0 的不用升级

## v0.6.0 · 2026-09-13

- 新增「叫醒闸门」：消息落盘后插件排一个一次性定时任务，把助手角色叫醒，由它自己读中转件、用自己的话转达，插件不再代替它开口
- 叫醒不成自动回退到即时总结直发，再不行还有取件环节兜底，三层保底，消息不会被吞
- 修两处实测踩出来的坑：平台那一栏填的是适配器名，会话串要的却是平台实例 id，现在自动解析；配置里的 PrivateMessage 直接拼会话串会被判 Invalid session，现在内置换算成 FriendMessage
- 新增配置项 wake_gatekeeper、wake_delay_seconds、umo_platform；全部配置项的提示重写成人话，把踩过的坑直接写在提示里
- 实测三秒延迟最稳：从落盘到助手开口大约五到六秒

## v0.5.0 · 2026-09-12

- 改名：AstrBot 侧插件统一为 `astrbot_plugin_dsh_gateway`，中文名「大肥鱼桥」
- 全面配置化：目录名、文件名、平台、前缀、总结提示词都能在面板里改，且都有默认值
- 收到消息即时总结转达，接口落盘即秒回，不等模型
- 事件流水改落 AstrBot 插件数据目录，不再写进项目目录
- 新增访问文件自签令牌，两侧只认目录和文件，谁先装都不会报错
- 补安装提示：加载时打印自检地址与三步走说明，配置项也都写上了人话提示
