# 提交插件市场时这样填

分类不是从 `metadata.yaml` 读的，是提交页面上手选的；我们仓库里没有这个字段，所以只能填表时选对。
市场现有分类里，「三方集成」最贴这个插件的定位，「工具」是第二选择。同类几个 DSH 桥接插件大都落在「其他」，
我们可以填得比它们准一点。

## 照抄这几行

| 表单那一栏 | 填什么 |
| --- | --- |
| 仓库地址 | `https://github.com/qzy033/astrbot_plugin_dsh_gateway` |
| 插件名 | `astrbot_plugin_dsh_gateway` |
| 显示名 | `大肥鱼桥` |
| 简介 | `让本地 dsh 借 AstrBot 的通道，由你的助手角色亲自把话讲给你听` |
| 版本 | `0.6.0` |
| 作者 | `qzy033` |
| 分类 | **三方集成**，备选「工具」，别留成默认的「其他」 |
| 标签 | `dsh, 桥接, 通知, astrbot` |
| 支持平台 | `aiocqhttp` |
| AstrBot 版本 | `>=4.0.0` |

简介长文用 `metadata.yaml` 里 `desc` 那段，页面会自动带出来，不用手打。

## 提交前后的注意事项

1. 仓库地址要干净，不带 `.git`、不带 `/tree/...`；市场只会 clone 仓库根目录，
   而那个仓库根目录就是插件本体，八件套齐全。
2. `metadata.yaml` 里的 `name`、`author`、`version` 必须和市场记录一致，
   所以以后每次改版本，市场那边要跟着更新一次。
3. 提交后等 CI 校验通过，再在面板市场里搜一次 `astrbot_plugin_dsh_gateway`，
   从市场装一遍、打开自检地址看到 `pong`，才算真的收录成功。
4. 提交完成后，回到这条记录确认分类不是「其他」；选错了可以在记录里编辑分类，不用重发代码。
